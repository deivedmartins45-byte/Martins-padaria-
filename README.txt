MARTINS PADARIA - PASSO A PASSO

0. Confirme que está no projeto martins-padaria (não no projeto antigo padaria-f963e).
1. Firebase > Authentication > Método de login > ative "E-mail/senha".
2. Firebase > Authentication > Usuários > Adicionar usuário:
   
   
3. Firebase > Firestore > Regras: cole o conteúdo de firestore.rules e publique.
4. Hospede a pasta no Firebase Hosting (ou outro endereço https).
5. No celular, abra o endereço no Chrome > 3 pontinhos > "Instalar aplicativo".

Antes de usar de verdade: remova o quadro "Acesso de demonstração" da tela de login.
